# RED DMA Bot Manager

## 使用方法
1. 把整个仓库目录保持完整（需要 data/ 与 index.js）
2. 双击 `RED_DMA_Bot_Manager.exe`（或 dist/ 下同名文件）
3. 在界面中编辑产品 / 固件状态 / 文案设置，点保存
4. 「部署」页可 Git 推送；Railway 连接本仓库后会自动部署

也可: python manager/app.py

## 注意
- 机器人已移除所有自动发送的虚拟货币地址
- 请勿在产品/文案中再填写钱包地址
- .env 仅本机调试，勿提交 Git

## 工单
- Railway 设置 `TICKET_PANEL_CHANNEL_ID` 为购票**文字频道**（当前为 `1486387508517535774`）
- 启动时会在该频道发布或更新开票面板（已有面板则编辑并置顶，不会每次重启刷一条新面板）
- 管理员也可执行 `/reload-data` 刷新面板上的产品按钮
- 点击产品后，在该频道下创建私密帖工单；帖内 @ 成员会把对方加入工单
- `TICKET_CATEGORY_ID` 已弃用：留着不会报错，但不会再在分类下新建文字频道
